How it works
Three steps to never forgetting again.
Engram runs as a background daemon on your machine. Your AI tools talk to it via a local HTTP API, MCP server, or our Python/JS SDKs — and so can anything else that needs a memory.
1

Install

One command: curl -fsSL https://engram.ellmstack.dev/install.sh | bash, then engram onboarding — encrypted vault, first memory, and a running daemon in about five minutes.

2

Connect

engram mcp install wires Claude Desktop, Cursor, Windsurf, and Claude Code to your vault in one command. Capture, search, and context become tools your AI just has.

3

Recall

Engram assembles relevant context for every query, reducing your LLM's token consumption by 40-70%. Forgetting is efficient — and green.

MCP everywhere
One memory. Every AI you use.
engram mcp install writes a merge-safe engram entry into every supported editor's MCP config — preserving whatever servers you already have — and prints a ready snippet for anything it can't detect. Capture once in Claude Desktop, recall it in Cursor.

Claude Desktop

Config merged into claude_desktop_config.json — no hand-editing, nothing overwritten.

Claude Code

One command: claude mcp add --scope user engram -- engramd-mcp --engramd-url http://127.0.0.1:8787

Cursor & Windsurf

Wired via ~/.cursor/mcp.json and ~/.codeium/windsurf/mcp_config.json — same one command.

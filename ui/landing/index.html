Engram — Your AI deserves a memory.

A local-first, encrypted memory vault that gives AI agents persistent recall across sessions.

curl -fsSL https://engram.ellmstack.dev/install.sh | bash

🔒 Zero-Knowledge Encryption

SQLCipher AES-256. Your memories never leave your machine in plaintext. Even the sync server can't read them.

🧠 Semantic Search

Auto-downloads an ONNX embedding model (23MB). Find memories by meaning, not just keywords. Zero config.

💻 AI-Native API

REST + WebSocket + MCP server. Claude Code, Cursor, Windsurf — one command to connect your AI tools.

⚖️ Memory Hygiene

Automatic decay, strengthening, and consolidation. Important memories get stronger; noise fades away.

🔄 Cross-Device Sync

E2E encrypted sync with AES-256-GCM + HMAC. Vector-clock conflict resolution. Self-hostable sync server.

🛡️ Privacy Controls

Full audit trail, purge by criteria, retention policies. You control what's stored and for how long.
